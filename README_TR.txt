Kuponum Android uygulaması

Bu depo, Android WebView tabanlı Kuponum uygulamasının kaynak kodunu içerir. APK, GitHub Actions üzerinden oluşturulur.

APK oluşturmak için Actions sekmesindeki Build Kuponum APK iş akışını çalıştırın. Başarılı derlemeden sonra Kuponum-APK artifact dosyasını indirin ve içindeki app-debug.apk dosyasını Android telefona kurun.

Uygulama kuponları cihazda yerel olarak saklar; gerçek bahis veya ödeme işlemi yapmaz.
